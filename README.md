### 👨‍💻 Sobre mí

Soy desarrollador y estudiante avanzado de **Análisis de Sistemas** (Instituto ORT Argentina, egreso 2027), con certificación como **AI Consultant**. Mi especialidad es unir la ingeniería de software tradicional con **inteligencia artificial aplicada**, transformando flujos manuales e ineficientes en arquitecturas autónomas y sistemas de alta disponibilidad.

- 🤖 **IA Generativa & Agentes:** Integración de LLMs (OpenAI, Anthropic, locales con Ollama), arquitecturas RAG, function calling y agentes autónomos.
- ⚡ **Automatización Inteligente:** Orquestación de pipelines complejos con n8n, webhooks y Python para reducir costos operativos y eliminar tareas repetitivas.
- 🚀 **Desarrollo Full Stack:** Aplicaciones web modernas con React, Next.js, Node.js y Python, diseñadas para consumir y renderizar flujos de IA en tiempo real (streaming, paneles interactivos).
- 📐 **Ingeniería & Análisis:** Modelado de sistemas (UML), código desacoplado y arquitecturas preparadas para producción.
