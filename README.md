### 👨‍💻 Sobre mí

Soy desarrollador Full Stack y estudiante de **Análisis de Sistemas** (Instituto ORT Argentina, egreso 2027). Me especializo en diseñar, analizar y programar sistemas que optimizan procesos de negocio, combinando desarrollo web moderno con automatización e inteligencia artificial.

- 🤖 **IA & Automatización:** Workflows con n8n, agentes autónomos y LLMs integrados a sistemas reales para optimizar tareas repetitivas.
- 🚀 **Full Stack:** Aplicaciones end-to-end con arquitectura modular, APIs RESTful y despliegue continuo en la nube (Vercel, Docker).
- 📐 **Análisis de Sistemas:** Modelado (UML), buenas prácticas de ingeniería, código limpio y mantenible.
- 🎯 **Mi foco:** Que el software resuelva un problema de negocio concreto y sea confiable en producción.
